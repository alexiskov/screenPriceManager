<h1>Price Screen Manager</h1>

Простой менеджер ценовых экранов для торговых точек. Позволяет превратить обычный телевизор с доступом в интернет в динамический мультимедиа-прайс-лист.

### 📋 Описание

Price Screen Manager — это веб-приложение, которое позволяет удалённо управлять контентом на телевизорах/мониторах в торговых точках. Менеджер через админ-панель настраивает группы экранов, задаёт количество слотов и загружает изображения, которые автоматически сменяют друг друга с заданным таймаутом.

### Как это работает

1. Админ создаёт группы экранов (например: «Магазин №1 — Витрина», «Магазин №2 — Касса»).
2. Для каждой группы настраивается количество слотов (длительность таймаута и синхронизация времени с сервером будет реализована позже).
3. В каждый слот загружается изображение (прайс-лист, акция, баннер и т.д.).
4. Телевизор в торговой точке открывает URL группы в браузере — и на нём по кругу показываются изображения из слотов с заданной периодичностью (пока каждые 10 сек происходит смена изображения).
5. Админ в любой момент может удалённо обновить контент — экраны подхватят изменения.

### Старт

В момент запуска программа сама создаст файл конфигурации с дефолтными значениями и самоподписанные сертификаты. Конфигурацию можно изменить и после запуска — сервер перечитает её.

Таким же образом нужно поступить с сертификатами, если у вас уже есть оформленные от доверенного центра.

> **💡 Запуск на сервере**
>
> Программа может быть запущена вами на сервере, выполнив команду в терминале Linux в директории проекта:

```bash
go run cmd/main.go
```
