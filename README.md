<h1>Price Screen Manager</h1>  
Простой менеджер ценовых экранов для торговых точек. Позволяет превратить обычный телевизор с доступом в интернет в динамический мультимедиа-прайс-лист.

<h3>📋 Описание</h3>
Price Screen Manager — это веб-приложение, которое позволяет удалённо управлять контентом на телевизорах/мониторах в торговых точках. Менеджер через админ-панель настраивает группы экранов, задаёт количество слотов и загружает изображения, которые автоматически сменяют друг друга с заданным таймаутом.

<h3>Как это работает</h3>
Админ создаёт группы экранов (например: «Магазин №1 — Витрина», «Магазин №2 — Касса»).

Для каждой группы настраивается количество слотов (длительность таймаута и синхронизация времени с сервером будет реализована позже).

В каждый слот загружается изображение (прайс-лист, акция, баннер и т.д.).

Телевизор в торговой точке открывает URL группы в браузере — и на нём по кругу показываются изображения из слотов с заданной периодичностью (пока каждые 10 сек происходит смена изображения).

Админ в любой момент может удалённо обновить контент — экраны подхватят изменения.
